#  Algorithm Visualiser

An interactive sorting algorithm visualiser built with **HTML, CSS and JavaScript**.

The project lets you generate random arrays and watch different sorting algorithms work step-by-step through animated visualisations.

## Features
*  Generate random arrays
*  Adjustable array size
*  Adjustable animation speed
*  Live comparison and swap counters
*  Sorting time measurement
*  Visual indicators for different sorting operations
*  Controls are disabled while an algorithm is running
*  Sorted-state animation
*  Clean, responsive interface

##  Sorting Algorithms

The visualiser currently supports:

* **Bubble Sort**
* **Selection Sort**
* **Insertion Sort**
* **Merge Sort**
* **Quick Sort**
* **Radix Sort**

Each algorithm has its own visualisation so you can see how the array changes while it is being sorted.

## Visualisation

Different colours are used to represent different parts of the algorithms:

* 🔴 **Red** — elements currently being compared or processed
* 🟡 **Yellow** — Quick Sort pivot
* 🟠 **Orange** — Selection/Insertion Sort focus
* 🟣 **Purple** — Merge Sort left section
* 🔵 **Cyan** — Merge Sort right section
* 💗 **Pink** — Radix Sort current element
* 🟢 **Green** — sorted elements

Radix Sort also includes animated **digit buckets** and a visual rearrangement phase.

##  Built With

* **HTML5** — page structure
* **CSS3** — styling and animations
* **JavaScript** — sorting algorithms, visualisation and controls

## 🚀 Running the Project

1. Clone the repository:

```bash
git clone https://github.com/slan-123/algorithm-visualiser.git
```

2. Open the project folder.

3. Open `index.html` in a browser, or use **VS Code Live Server**.

No additional dependencies are required.
